SplitLocker – Android Ransomware Educational Project

SplitLocker is an Android-based ransomware research and educational project developed using Java and Kotlin, with XML for the user interface.

The project is designed to help cybersecurity enthusiasts, Android developers, and security researchers understand how Android ransomware works, how file-locking mechanisms operate, and why ransomware poses a serious security threat.

How Ransomware Works

Traditional ransomware typically follows a sequence of operations:

Device/File Access: Attempts to access files stored on the target device.
File Encryption: Encrypts or locks selected files, making their contents inaccessible to the user.
Decryption Key: Keeps the affected files inaccessible until the corresponding decryption key becomes available.
Ransom Demand: Displays a ransom note demanding payment in exchange for the promised recovery key.
File Recovery: Files may be restored using the correct decryption key, provided the encryption and recovery mechanisms work as intended.
